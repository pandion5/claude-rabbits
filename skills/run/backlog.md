# 백로그 규약

SKILL.md 단계 0(무인자 호출)·단계 6(채택 런 종료)에서 백로그가 발동했을 때만 읽는다.

## 단계 0 — 채택

- 작업이 비어 있으면 `.rabbits/backlog.md`를 확인한다: 미완료 항목(`- [ ]`)이 있으면
  **최상단 미완료 1개**를 이 런의 작업으로 채택하고 "백로그 n번째/총 m건"(체크 포함 전체
  순번 n / 전체 m)을 나레이션한다.
- 백로그가 없거나 미완료 항목이 없으면 기존대로 사용자에게 작업만 요청한다(자율의 유일한 필수 입력).

## 단계 6 — 처리·연쇄

- **백로그 처리**: 이 런의 작업이 백로그에서 채택됐다면 성공/실패 무관하게 해당 항목을
  소비한다 — `- [x] 항목`으로 체크하되, 미해결 종료(사다리 5단계 소진)면
  `- [x] 항목 (미해결: 사유 1구)`로 표기해 은폐하지 않는다. 미완료 항목이 남아 있으면 마커를
  삭제하지 않고 — 마커 존재 자체가 Stop hook 가드로 하여금 연쇄를 강제하는 원리다 — 전환을
  나레이션한 뒤 **단계 0부터 새 런을 재진입**한다(런 상한·코칭 카운트는 재진입마다 리셋).
  **연쇄는 한 호출당 최대 10건** — 초과 시 잔여 백로그를 최종 리포트에 명시하고 마커 삭제·
  종료한다(다음 무인자 호출로 재개). 백로그가 비었거나 연쇄 상한에 닿았을 때만 아래 마커
  삭제로 진행한다.
