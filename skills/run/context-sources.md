# 컨텍스트 소스 — 지식베이스 연동·리포별 설정

SKILL.md 단계 1 컨텍스트 팩 조립에서 (d) 지식베이스 색인 또는 (e) 리포별 설정이 발동했을 때만 읽는다.
팩 항목 (a)(b)(c)에 이어 붙이는 선택 항목이다.

## (d) 지식베이스 연동

세션 컨텍스트에 지식베이스 색인(기술별 노하우 페이지 목록)이 주입돼 있으면 매칭 상위 2~3개
기술 페이지만 Read해(전체 로드 금지) 검증된 노하우(성공 패턴·함정)를 포함, 6개월 이상 지난
항목은 "재검증 전 맹신 금지" 단서를 붙인다(색인 없으면 생략).

## (e) 리포별 설정

대상 리포에 `.rabbits/config.md`가 있으면 Read해 팩에 포함 — 거기 적힌 코드 표준·관례가 워커
`{{제약}}`과 코드 산출물 표준의 전역 기본값을 **대체**한다(없으면 생략, 대장이 임의 생성하지
않는다 — 사용자가 요청할 때만 초안 작성).

config.md가 담을 수 있는 항목: 코드 표준·리포 관례, 그리고 **런 보고서 집중 경로**(단계 6 보고서를
대상 리포 대신 한곳에 모을 절대경로 — 다중 프로젝트 회고용). 형식은 섹션 제목 + 절대경로 1줄:

```markdown
# 런 보고서 경로
E:/work/rabbits-reports
```
